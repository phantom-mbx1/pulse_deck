# Security Policy

## Local-First Security Model
PulseDeck is designed to run locally and binds its HTTP server to `127.0.0.1` (loopback) by default. Telemetry samples and snapshots stay in your local SQLite database unless you explicitly export or share them.

## Reporting a Vulnerability
Please do not report security vulnerabilities in public issues. Open a private security advisory on GitHub or contact the repository maintainers directly with reproduction steps and affected versions.
